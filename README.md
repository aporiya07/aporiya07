## About

I'm an AI Engineer at **QuantumBot**, building production AI systems: RAG pipelines, multilingual voice assistants, and document intelligence. I've worked on 10+ AI applications, taking each one from prototype to a system that runs daily in a real environment.

My path into AI started with hardware. I ran a 3D printing service, then completed a master's in Communication Systems and Networks at Cologne University of Applied Sciences. For my thesis I built a real-time computer vision system that detects defects in 3D prints, which meant creating and labeling the training dataset myself, from raw images to a model-ready export.

That hands-on data work is why I also take on **freelance data annotation and labeling projects**. I understand what a model needs from its training data, because I've built the dataset, trained the model, and seen where poor labels break things.

## Data annotation & labeling

I annotate image and video data for machine learning teams, with an engineer's eye for label consistency and for how the data will actually be used in training.

| Service | What I deliver |

### Experience

**Defect-detection dataset for 3D printing** (master's thesis)

Built and labeled the full dataset for a real-time print-defect detector, then trained and compared models on it.

- **~1,000 source images** captured and labeled by hand
- **1,000+ annotated defect instances** across a 3-class taxonomy: spaghetti, warping, and layer shift
- **Bounding boxes and 550+ polygon segmentation masks**
- Augmented to a **2,355-image** dataset with train / validation / test splits
- Used to train and benchmark **YOLOv7, YOLOv8-L, and YOLOv8-X**, plus TensorFlow (MobileNet, ResNet) baselines

**Robot task video annotation** (freelance)

- Annotated videos of robots performing a range of different tasks, labeling the actions and task steps in each clip for a robotics training dataset.

### How I work

1. **Agree on guidelines first.** Classes, edge cases, and examples are written down before labeling starts.
2. **Pilot batch.** A small sample is labeled and reviewed with you before the full run.
3. **Consistent labeling.** Each batch is checked against the guidelines before delivery.
4. **Clean delivery.** Data is exported in your format and ready for training.

**Tools:** Roboflow, Python, OpenCV, YOLO (v7 / v8), TensorFlow Object Detection API. I'm comfortable picking up a client's own platform quickly.
