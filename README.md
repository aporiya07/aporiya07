### [ImPrompt](https://github.com/aporiya07/imprompt): reference images to image-model prompts

Takes a reference image and writes a prompt for a specific image model. Instead of a generic caption, it keeps the composition, people's poses and how they relate to each other, the scene layout and the lighting, and it notes what it isn't sure about.

- Typed **Visual DNA** and creative-intent representations, with an adapter for each target model.
- Handles multiple people, occlusion, collages, moodboards and multi-panel continuity.
- Deterministic checks for prompt coverage, unsupported assumptions and repetition.

**Stack:** Python · FastAPI · Pydantic · React · Vision/LLM APIs

### [Lead Miner](https://github.com/aporiya07/lead-miner-gen): business lead discovery

Finds businesses by industry, niche and location, extracts their contact details into structured fields with AI, and shows the results in a dashboard.

- FastAPI backend using Firecrawl, with CSV export.
- Dashboard for reviewing and managing extracted records.

**Stack:** Python · FastAPI · Firecrawl · JavaScript · CSS
